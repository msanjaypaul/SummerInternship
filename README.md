# InternHub - Summer Internship Finder

A ready-to-use website for students to discover summer internships in one place.

## What's included
- Listings from **official company websites** and **trusted aggregators**.
- Direct links for **Apply now** and **View source** on each card.
- Rich filters: search, domain, location, work mode, internship type, source, paid/unpaid, and deadline.
- Student support sections:
  - application checklist
  - suggested timeline
  - interview prep focus
  - trusted source directory (fallback links if any posting moves)

## Run locally
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`.
